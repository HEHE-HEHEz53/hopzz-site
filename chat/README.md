# 鲸鱼娘在线（ai.hopzz.top）—— 使用说明

## 一句话

打开 **https://ai.hopzz.top** → 输密码 → **手机上看到的就是你电脑里 DSH Harness 的真实内容**：真实的项目、真实的会话、真实的历史记录，还能看到当前用的模型、模式、权限和装了哪些插件。

不是另开一套对话，是**同一份数据**。

---

## 1. 怎么用

1. 手机浏览器打开 **https://ai.hopzz.top**
2. 输密码（见第 3 节）
3. 左边（手机上点左上角 **☰**）是**按项目分组的会话列表**
4. 点任意一个会话 → 右边显示它的**真实历史记录**
5. 在底部输入框发消息 → 这条消息会发进**那个真实的会话**里

登录状态保持 30 天，不用每次输密码。

**前提**：电脑得开着、DSH 得在运行。真正干活的是你电脑。

---

## 2. 界面上都有什么

### 侧栏（按项目分组）

```
＋ 新建会话
─────────────
work
  ● 搭建服务器并配置硬件      18:32   ← 正在运行
    你好，自我介绍一句话       18:03
    记住数字 41               17:47
cj
    ...
MAKASH
    ...
未归属
    欢迎新人消息              18:38
```

- 分组名 = 你在 DSH 里建的项目（工作区）
- 会话标题、时间、**蓝点表示这一轮正在跑**
- 点一下切换会话

### 主区
- 顶栏：`☰` / 会话标题 / 连接状态点 / `ℹ` / `⚙` / 主题 / 退出
- 消息区：真实的 user / assistant 消息；工具调用显示成一行灰色小标签
- 输入框：Enter 发送、Shift+Enter 换行

### ℹ 信息面板
点右上角 **ℹ**，能看到：
| 项目 | 内容 |
| --- | --- |
| 模型 | 当前 provider / model，以及所有可选模型 |
| 模式 | 当前会话的 preset（standard / ptc / minimal / cordis），以及全部可用模式 |
| 权限 | 当前会话的权限档位（如 `workspace-write`、`danger-full-access`） |
| 插件 | 已安装的 bundle 列表 `名称@版本`，禁用的灰显 |
| 项目 | 所有工作区及其路径 |

### ＋ 新建会话
弹窗里选一个项目（或不指定），就会在电脑上**真的新建一个 DSH 会话**，然后自动切过去。

## 3. 密码、改密码、锁定

**当前登录密码**：`（见服务器 /opt/hopzz-chat/.env）`

服务器上查看/修改：

```bash
grep CHAT_PASSWORD= /opt/hopzz-chat/.env      # 查看初始密码
```

### 改密码
在网页里点右上角 **⚙** → 原密码 + 新密码（≥8 位）+ 确认 → 保存。
改完所有设备的旧登录态立刻失效，当前这台自动续上。

### 连续输错 5 次 → 锁定 15 分钟
- 前 4 次会提示「还能试 N 次」
- 第 5 次锁定，网页显示倒计时，**锁定期间密码对了也进不去**
- 急着用就执行：

```bash
bash /root/unlock.sh
```

密码以 PBKDF2-SHA256（20 万次迭代）哈希存在服务器数据库里，不存明文。

## 4. 它是怎么工作的

```
  手机浏览器
     │ HTTPS / WSS
     ▼
  ai.hopzz.top   （中继服务器，只负责鉴权和转发，不存聊天内容）
     ▲
     │ 插件主动外连（WSS），不需要公网 IP
     │
  你电脑上的 DSH Harness
     ├─ sessionController.list()    → 真实会话列表
     ├─ sessionController.page()    → 真实历史记录
     ├─ sessionController.prompt()  → 往真实会话发消息
     ├─ workspaceRegistry.list()    → 项目（工作区）
     ├─ agentPresets.list()         → 模式
     ├─ modelCatalog()              → 模型
     └─ pluginManager.listBundles() → 插件
```

**关键点：连接方向是「你电脑主动连出去」**，跟浏览器上网一样，所以路由器不用做任何设置，也不用开隧道、不用公网 IP。

服务器**不保存任何聊天内容**，每次打开都是从你电脑里现读的。

---

## 5. 注意

- **手机上网看到的历史就是电脑上的历史**，你在手机上发的消息会真的写进那个会话，会改变它的历史记录。
- **正在运行的会话**（蓝点）在跑这一轮时，你发的消息会排队，等这一轮结束再处理。
- 电脑关机 / DSH 没开 → 网页能打开、能看列表（缓存），但发消息会提示「电脑端未连接」。
- 关掉整个功能：在 DSH 插件管理里禁用「手机网页对话」，再执行
  `systemctl stop hopzz-chat && systemctl disable hopzz-chat`。

## 7. 出问题了怎么查

### 页面打不开 / 502

```bash
systemctl status hopzz-chat --no-pager
journalctl -u hopzz-chat -n 40 --no-pager
```

### 列表一直是空的 / 提示「电脑端未连接」

```bash
# 看插件有没有连进来
journalctl -u hopzz-chat --since "-10 min" --no-pager | grep '插件已连接'
```

看到 `[relay] 插件已连接，版本 2.0.3` 就是正常的。
如果没看到：确认电脑上 DSH 在运行、插件管理里「手机网页对话」是启用的。

### 发消息提示「电脑端未连接，请确认 DSH 正在运行」

插件掉线了。等它自动重连（最多 30 秒），或者重启一下 DSH。

### 历史里看不到某条消息

可能被当作「注入的运行时上下文」过滤掉了（那些不是你发的话，是 Harness 自动注入的，故意不显示）。

### 登录提示「尝试次数过多，已锁定」

```bash
bash /root/unlock.sh
```

## 8. 新功能（第五版）

### 8.1 站点改名 + 换域名
- 站点名：**鲸鱼娘在线**
- 主地址：**https://ai.hopzz.top**
- https://chat.hopzz.top 保留为等价别名（同样的服务，两个域名都能用）

### 8.2 二次元主题
樱花粉 / 薰衣草紫 / 天蓝青渐变，深紫底 + 奶白浅底，大圆角，粉色选中竖条，粉色运行脉冲，小鲸鱼头像。右上角仍可切深色/浅色。

### 8.3 可以切模型 / 切模式（信息面板）
点右上角 **ℹ**：
- **模型**：点任意模型即可切换（调 DSH 的 sessionController.selectModel）
- **模式**：点任意 preset（standard / ptc / minimal / cordis）即可切换（调 gentPresets.select）
- 会话正在运行时切换会失败，提示「会话正在运行，稍后再切换」

### 8.4 可以启用 / 关闭插件
信息面板里每个插件（bundle）右边有开关：
- 点开关会**真的改动你电脑上 DSH 的插件启用状态**（调 pluginManager.setBundleEnabled）
- @local/dsh-web-relay 就是本页面自己的插件，标了「本页面」，关掉它会断线，需要二次确认

### 8.5 项目分组更准
- 有归属工作区的会话按工作区分组
- **没有归属**的（比如 QQ 机器人的会话）按 cwd 分组，标题取路径最后两段，不再全堆在「未归属」
- 会话项右侧有模式 / 模型的小徽标

> ⚠️ **上面 8.3 和 8.4 需要重启一次 DSH 才生效。**
> 原因：这些功能是新版插件（2.1.0）才有的，而电脑上正在运行的还是 2.0.3，
> 热重载被一个卡住的 HMR 事务锁住了，只能重启解开。
> 重启方式：关掉 DSH 桌面端再打开。重启后插件会自动连到 i.hopzz.top。
> 没重启之前，模型/模式/插件这三处会提示「需要重启 DSH 才能使用这个功能」，其他功能都正常。
