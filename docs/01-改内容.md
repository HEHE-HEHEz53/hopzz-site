# 01 · 怎么改主页上的内容

主页的文字、作品、联系方式全在 **一个 HTML 文件**里，改完发布即可，不需要重启任何服务。

> 记住流程：**改本地源码 → 跑 `deploy.ps1` → 浏览器 Ctrl+F5 强刷**

---

## 0. 准备工作

用记事本或 VS Code 打开：

```
D:\DSH\work\deploy\site\index.html
```

我在文件里留了 `<!-- ✏️ 改这里：... -->` 的注释，**用编辑器的搜索功能搜 `✏️` 就能跳到我标好的所有位置。**

---

## 1. 改名字和一句话介绍

搜 `你好，我是`，你会看到：

```html
<h1 class="reveal">
  你好，我是 <span class="grad">Hopzz</span>
</h1>
```

- 把 `Hopzz` 换成你的名字或昵称
- `<span class="grad">` 包住的部分会显示成渐变彩色，不想要颜色就把 `<span class="grad">` 和 `</span>` 删掉

下面那句 `class="lead"` 的 `<p>` 是自我介绍，直接改里面的中文。

再往下：

```html
<p class="eyebrow">
  <span class="pulse" aria-hidden="true"></span>
  全栈开发 · 硬件折腾爱好者
</p>
```

这一行是首屏顶部的小标签，改成你的身份。

---

## 2. 改"关于我"

搜 `关于我`，找到 `id="about"` 那一段。里面有两个 `<p>`，是正文；旁边那张小卡片是"坐标/在做/工具/状态"。

```html
<p>
  我在做前端和后端开发，也喜欢嵌入式——ESP32、传感器、继电器这些。
  ...
</p>
```

直接把中文替换掉即可。**段落里不要出现 `<` 或 `>`**，否则会被当成标签。

右侧小卡片改这里：

```html
<div><dt>坐标</dt><dd>中国 · 远程</dd></div>
```

`<dt>` 是左边的标签，`<dd>` 是右边的值。

---

## 3. 改技能标签

搜 `id="skills"`，你会看到三组：

```html
<div class="skill-group reveal">
  <h3>前端</h3>
  <ul class="chips">
    <li>HTML / CSS</li><li>JavaScript</li><li>响应式布局</li><li>交互与动画</li>
  </ul>
</div>
```

- `<h3>` 是分组名（前端 / 后端 / 硬件），可以随便改
- 每个 `<li>...</li>` 是一个标签
- **加一个标签**：在 `</ul>` 前面插一行 `<li>新技能</li>`
- **删一个标签**：把整个 `<li>...</li>` 删掉

---

## 4. 改 / 加作品卡片

搜 `id="work"`。一个作品长这样：

```html
<article class="project reveal">
  <div class="project-top">
    <span class="project-tag">网站</span>
    <span class="project-year">2026</span>
  </div>
  <h3>这个个人主页</h3>
  <p>Nginx + FastAPI + SQLite，从零手写样式与动画，没有用任何前端框架。</p>
  <ul class="project-stack"><li>Nginx</li><li>FastAPI</li><li>Let's Encrypt</li></ul>
</article>
```

要**新增一个作品**，就复制上面这一整块（从 `<article` 到 `</article>`），粘贴到上一个作品后面，然后改里面的 4 处文字：

1. `project-tag`：分类，如 `网站` / `硬件` / `运维`
2. `project-year`：年份
3. `<h3>`：项目名
4. `<p>`：一句话说明
5. `project-stack` 里的 `<li>`：技术栈

三列布局是自动的，加到 4 个会自动换行。

---

## 5. 改联系方式

搜 `id="contact"`：

```html
<a class="btn btn--primary" href="mailto:you@example.com">you@example.com</a>
<a class="btn btn--ghost" href="https://github.com/" target="_blank" rel="noopener">GitHub</a>
```

- 邮箱：两处都要改（`href="mailto:你的邮箱"` 和标签文字）
- GitHub：把 `https://github.com/` 换成你的主页地址
- 想加微信？加一行 `<a class="btn btn--ghost" href="#">微信：你的号</a>` 就行（微信不能直接跳转，做成文字提示即可）

> ⚠️ 邮箱写出来会被爬虫抓取收到垃圾邮件。介意的话可以写成 `you (at) example.com` 这种形式。

## 6. 改页脚

搜 `class="foot"`：

```html
<p>© <span id="year">2026</span> Hopzz · 用 Nginx + FastAPI 手搓</p>
```

`id="year"` 那个会自动变成当前年份，别删；`Hopzz` 可以改成你的名字。

## 7. 改配色（进阶，可选）

配色全在 `D:\DSH\work\deploy\site\assets\style.css` 开头的变量里：

```css
:root {
  --accent: #3ef0c0;      /* 主色（青绿） */
  --accent-2: #5b8cff;    /* 次色（蓝） */
  --bg: #0a0e14;          /* 深色主题背景 */
  --text: #e8edf5;        /* 深色主题文字 */
}
```

把 `--accent` / `--accent-2` 换成别的颜色代码（例如 `#ff7a45` 橙、`#b57bff` 紫），整个站的渐变、按钮、高亮会一起变。

浅色主题在下面的 `html[data-theme="light"]` 里，同样的变量名。

## 8. 发布出去

改完后，在 PowerShell 里运行：

```powershell
powershell -ExecutionPolicy Bypass -File D:\DSH\work\deploy.ps1
```

看到 `==> 完成` 就成了。然后浏览器打开 https://hopzz.top ，按 **Ctrl + F5** 强制刷新（普通 F5 可能读到旧缓存）。

> 静态网页改完是**立刻生效**的，不需要重启后端、也不用重启 Nginx。

## 9. 常见问题

**Q：改完刷新没变化？**
A：三层缓存，按顺序排查：
1. 浏览器缓存 → `Ctrl + F5`
2. 手机/别处开了旧页面 → 关掉重开
3. 文件没传上去 → 重新跑 `deploy.ps1`，看它有没有报错

**Q：改完页面全白了？**
A：多半是 HTML 标签被改坏了。用 `Ctrl + Z` 撤销，或者看看是不是删掉了某个 `</div>`。发布前可以先把文件拖进浏览器本地打开看效果（双击 `index.html` 也行，只是没有实时数据）。

**Q：想加一个全新的页面（比如 /blog）？**
A：在 `deploy\site\` 下新建 `blog.html`，照着 `index.html` 的头部抄一份，然后发布，访问 https://hopzz.top/blog.html 即可。以后要做得复杂了，再考虑换静态站生成器或博客系统。

**Q：我想加一个"功能"（留言板、网盘、后台……）？**
A：后端已经有 `/api` 这个壳了。加功能就是在 `/opt/hopzz-api/app/main.py` 里加接口，然后在 `assets/app.js` 里调它。**告诉我你想要什么功能，我帮你写。**
