# 04 · 命令速查表

复制粘贴用的。左边是"我要干什么"，右边是命令。

---

## 本机（Windows PowerShell）

| 我要… | 命令 |
| --- | --- |
| 连上服务器 | `ssh -F D:\DSH\work\.ssh\config vps` |
| 发布网站修改 | `powershell -ExecutionPolicy Bypass -File D:\DSH\work\deploy.ps1` |
| 从服务器下载文件 | `scp -F D:\DSH\work\.ssh\config vps:/root/backup/ D:\DSH\work\backup\` |
| 上传文件到服务器 | `scp -F D:\DSH\work\.ssh\config D:\DSH\work\某文件 vps:/root/` |
| 查看网站 | 浏览器打开 https://hopzz.top |

---

## 服务器上 · 状态检查

| 我要… | 命令 |
| --- | --- |
| 后端是否活着 | `systemctl status hopzz-api --no-pager` |
| Nginx 是否活着 | `systemctl status nginx --no-pager` |
| 后端接口是否通 | `curl -s http://127.0.0.1:8000/api/health` |
| 网站是否通 | `curl -sI https://hopzz.top \| head -1` |
| 整机资源占用 | `htop`（q 退出） |
| 磁盘剩余 | `df -h /` |
| 内存使用 | `free -h` |
| 谁在监听端口 | `ss -tlnp` |

---

## 服务器上 · 重启与重载

| 我要… | 命令 |
| --- | --- |
| 改了后端代码后生效 | `systemctl restart hopzz-api` |
| 改了 nginx 配置后生效 | `nginx -t && systemctl reload nginx` |
| 检查 nginx 配置语法 | `nginx -t` |
| 全部重启 | `systemctl restart nginx hopzz-api` |
| 重启整台服务器 | `reboot` |

---

## 服务器上 · 日志

| 我要… | 命令 |
| --- | --- |
| 后端日志实时滚动 | `journalctl -u hopzz-api -f` |
| 后端最近 50 行 | `journalctl -u hopzz-api -n 50 --no-pager` |
| 后端今天的错误 | `journalctl -u hopzz-api --since today -p err --no-pager` |
| Nginx 访问日志 | `tail -f /var/log/nginx/access.log` |
| Nginx 错误日志 | `tail -n 50 /var/log/nginx/error.log` |
| 被封锁的 IP | `fail2ban-client status sshd` |
| 解封一个 IP | `fail2ban-client set sshd unbanip 1.2.3.4` |
| 谁登录过 | `last -20` |

---

## 服务器上 · 数据

| 我要… | 命令 |
| --- | --- |
| 看最新 10 条传感器数据 | `sqlite3 -header -column /opt/hopzz-api/data/hopzz.db "SELECT * FROM telemetry ORDER BY id DESC LIMIT 10;"` |
| 数据总条数 | `sqlite3 /opt/hopzz-api/data/hopzz.db "SELECT COUNT(*) FROM telemetry;"` |
| 删 30 天前旧数据 | `sqlite3 /opt/hopzz-api/data/hopzz.db "DELETE FROM telemetry WHERE created_at < datetime('now','-30 day');"` |
| 看每天访问量 | `sqlite3 -header -column /opt/hopzz-api/data/hopzz.db "SELECT * FROM visits ORDER BY day DESC LIMIT 14;"` |
| 备份数据库 | `sqlite3 /opt/hopzz-api/data/hopzz.db ".backup '/root/backup/hopzz-$(date +%F).db'"` |
| 看设备令牌 | `grep DEVICE_TOKEN= /opt/hopzz-api/.env` |

> 用 `sqlite3` 时如果中文显示成乱码，先执行一次 `export LANG=C.UTF-8`。

## 服务器上 · 测试接口

| 我要… | 命令 |
| --- | --- |
| 跑完整自检（会写入一条测试数据） | `bash /root/test_api.sh` |
| 手动上报一条数据 | `curl -X POST https://hopzz.top/api/telemetry -H 'Content-Type: application/json' -H "X-Device-Token: $(grep -o 'DEVICE_TOKEN=.*' /opt/hopzz-api/.env \| cut -d= -f2)" -d '{"device_id":"manual","temperature":25.0,"humidity":50.0}'` |
| 看最新一条 | `curl -s https://hopzz.top/api/telemetry/latest` |
| 看服务器状态 | `curl -s https://hopzz.top/api/status` |
| 清空测试数据 | `sqlite3 /opt/hopzz-api/data/hopzz.db "DELETE FROM telemetry WHERE device_id='self-test';"` |

## 服务器上 · 证书与防火墙

| 我要… | 命令 |
| --- | --- |
| 看证书到期时间 | `certbot certificates` |
| 演练续期 | `certbot renew --dry-run` |
| 看自动续期定时器 | `systemctl list-timers certbot.timer` |
| 看防火墙规则 | `ufw status numbered` |
| 开一个端口 | `ufw allow 8080/tcp` |
| 关一个端口 | `ufw delete allow 8080/tcp` |

## 文件位置速查

| 路径 | 是什么 |
| --- | --- |
| `/var/www/hopzz.top/` | 网页文件 |
| `/opt/hopzz-api/app/main.py` | 后端代码 |
| `/opt/hopzz-api/.env` | 设备令牌（机密） |
| `/opt/hopzz-api/data/hopzz.db` | 数据库 |
| `/etc/nginx/sites-available/hopzz.top.conf` | Nginx 配置 |
| `/etc/systemd/system/hopzz-api.service` | 后端自启配置 |
| `/root/install.log` | 部署日志 |
| `/root/test_api.sh` | 接口自检脚本 |
