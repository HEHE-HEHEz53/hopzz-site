# 03 · 安全建议（请先看第 1 条）

---

## 1. ⚠️ 立刻改掉 root 密码

**原因**：你的 root 密码是直接在聊天里明文发给我的。哪怕这次通信是安全的，密码一旦以明文形式出现过，就应该当成"已泄露"处理——这是运维的基本习惯。

**怎么做**（2 分钟）：

1. 连上服务器：
   ```powershell
   ssh -F D:\DSH\work\.ssh\config vps
   ```

2. 执行改密码命令：
   ```bash
   passwd
   ```
   按提示输两遍新密码。**输入时屏幕不显示任何字符，这是正常的**，输完直接回车。

3. 新密码要求：
   - 至少 16 位
   - 大小写字母 + 数字 + 符号混合
   - **不要**用生日、名字拼音、`Hejia`+数字这类组合
   - 用密码管理器生成，或者用一句话的变体：`WoDeMiMa-2026-XiaTian!ZhenRe`

4. 改完后**别退出当前会话**，新开一个 PowerShell 窗口测试密码能否登录：
   ```powershell
   ssh -o PubkeyAuthentication=no root@64.83.20.24
   ```
   能进就说明新密码生效了。

> 顺便说明：我现在给你配的是 **密钥登录**，改完密码后你日常用 `ssh -F ... vps` 根本不走密码，所以改密码不影响便利性，只是把风险堵上。

## 2. 保管好你的密钥文件

```
D:\DSH\work\.ssh\id_ed25519
```

**这是私钥，等于服务器的钥匙。** 记住三条：

- ❌ 不要发给任何人（包括我）
- ❌ 不要上传到 GitHub / 网盘 / 微信
- ❌ 不要放在公共电脑上

如果怀疑泄露了，在服务器上执行下面这行立刻作废所有密钥登录：

```bash
> /root/.ssh/authorized_keys
```

然后告诉我，我帮你重新生成一对。

## 4. 可选进阶：彻底关闭密码登录（推荐，但先做第 1 条）

密钥登录配好之后，密码登录其实是个多余的风险入口（会被不停爆破）。确认密钥登录**稳定可用**之后再关：

```bash
# 1. 确认密钥登录没问题后，创建配置
cat > /etc/ssh/sshd_config.d/20-no-password.conf <<'EOF'
PasswordAuthentication no
KbdInteractiveAuthentication no
EOF

# 2. 检查配置语法（必须通过）
sshd -t

# 3. 重载（不会断开已有连接）
systemctl reload ssh

# 4. 立刻用新窗口测试：下面的命令应该被拒绝
#    ssh -o PubkeyAuthentication=no root@64.83.20.24
```

**⚠️ 关闭前务必确认**：你新开一个窗口 `ssh -F D:\DSH\work\.ssh\config vps` 能正常进。
万一失误了：登录你买服务器的**商家控制台**（VPS 面板一般都有 "VNC / 远程控制台"），用里面登进去把这两个文件删掉再重启 ssh 即可。

> 想恢复密码登录：删掉 `/etc/ssh/sshd_config.d/20-no-password.conf` 后 `systemctl reload ssh`。

## 5. 设备令牌（硬件的密码）怎么管

位置：`/opt/hopzz-api/.env` 里的 `DEVICE_TOKEN=`。当前值我在部署时打印过，你也可以随时查看：

```bash
grep DEVICE_TOKEN= /opt/hopzz-api/.env
```

**什么时候要换令牌**：如果你把令牌写进代码后又不小心把代码发到公开的地方了。

换令牌的步骤：

```bash
# 1. 生成新令牌并写入
NEW=$(openssl rand -hex 24)
sed -i "s/^DEVICE_TOKEN=.*/DEVICE_TOKEN=$NEW/" /opt/hopzz-api/.env
echo "新令牌：$NEW"

# 2. 重启后端生效
systemctl restart hopzz-api
```

然后**必须**去改硬件的代码（`03_post_to_server.ino` 里的 `DEVICE_TOKEN`），重新烧录，否则硬件会被拒绝（401）。

## 6. 几个"不要做"

- ❌ **不要把服务器当重要数据仓库**——VPS 可能出故障，重要东西自己电脑留一份
- ❌ **不要 `chmod 777` 任何目录**来"解决权限问题"，那等于把门拆了
- ❌ **不要装来路不明的一键脚本**（`curl xxx | bash`），这是挖矿木马最常见的入口
- ❌ **不要在 `/var/www/hopzz.top` 里放 `.env` 之类带密码的文件**，那个目录是公开可下载的
- ❌ **不要关掉 80 端口**，否则 HTTPS 证书续期会失败，三个月后网站就打不开了
