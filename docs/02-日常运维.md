# 02 · 日常运维

日常操作其实很少。这份文档把最常用的命令都列出来，**复制粘贴就能用**。

---

## 0. 先学会连上服务器

在 **PowerShell**（不是 CMD）里执行：

```powershell
ssh -F D:\DSH\work\.ssh\config vps
```

看到 `root@ser562561000699:~#` 就说明进去了。**输入 `exit` 回车退出。**

> 为什么不用输密码？我给你配了 SSH 密钥（`D:\DSH\work\.ssh\id_ed25519`），比密码更安全也更快。
> **这个文件千万别发给别人**，谁拿到它就等于拿到你的服务器。

如果嫌命令太长，可以在 `C:\Users\HeHep\.ssh\config` 里加一段（可选）：

```
Host vps
  HostName 64.83.20.24
  User root
  IdentityFile D:/DSH/work/.ssh/id_ed25519
```

以后直接 `ssh vps` 就行。

## 1. 查看网站/后端是否正常

```bash
# 后端服务状态（看到 active (running) 就是好的）
systemctl status hopzz-api --no-pager

# Nginx 状态
systemctl status nginx --no-pager

# 后端是否响应
curl -s http://127.0.0.1:8000/api/health

# 网站是否响应
curl -sI https://hopzz.top | head -1
```

---

## 2. 重启服务

```bash
# 只重启后端（改了后端代码后需要）
systemctl restart hopzz-api

# 只重载 Nginx（改了 nginx 配置后，不中断用户）
nginx -t && systemctl reload nginx

# 全部重启
systemctl restart nginx hopzz-api
```

> 改了**网页文件**（html/css/js）不需要重启任何东西，直接刷新浏览器。
> 改了**后端 Python 代码**必须 `systemctl restart hopzz-api`。
> 改了**Nginx 配置**必须 `nginx -t && systemctl reload nginx`（`nginx -t` 是检查语法，一定要先跑）。

## 3. 看日志（出问题时最有用的东西）

```bash
# 后端日志，实时滚动（Ctrl+C 退出）
journalctl -u hopzz-api -f

# 后端最近 50 行
journalctl -u hopzz-api -n 50 --no-pager

# 只看今天的错误
journalctl -u hopzz-api --since today -p err --no-pager

# Nginx 访问日志（谁访问了什么）
tail -f /var/log/nginx/access.log

# Nginx 错误日志
tail -n 50 /var/log/nginx/error.log

# 被 fail2ban 封了哪些 IP
fail2ban-client status sshd

# 解封某个 IP
fail2ban-client set sshd unbanip 1.2.3.4
```

## 4. 看/管数据库里的数据

```bash
# 看最新 10 条硬件数据
sqlite3 -header -column /opt/hopzz-api/data/hopzz.db \
  "SELECT * FROM telemetry ORDER BY id DESC LIMIT 10;"

# 看有多少条
sqlite3 /opt/hopzz-api/data/hopzz.db "SELECT COUNT(*) FROM telemetry;"

# 删除 30 天以前的旧数据（防止数据库无限变大）
sqlite3 /opt/hopzz-api/data/hopzz.db \
  "DELETE FROM telemetry WHERE created_at < datetime('now','-30 day');"

# 每天访问量
sqlite3 -header -column /opt/hopzz-api/data/hopzz.db "SELECT * FROM visits ORDER BY day DESC LIMIT 14;"
```

## 5. 备份

### 备份数据库（最该备份的东西）

在**服务器上**：

```bash
mkdir -p /root/backup
sqlite3 /opt/hopzz-api/data/hopzz.db ".backup '/root/backup/hopzz-$(date +%F).db'"
ls -lh /root/backup/
```

在**你电脑上**把备份下载回来：

```powershell
scp -F D:\DSH\work\.ssh\config vps:/root/backup/ D:\DSH\work\backup\
```

### 备份网页和后端源码

不用特意备份——**你电脑上的 `D:\DSH\work\deploy\` 就是源码**，整个文件夹复制走就行。

### 建议加个自动备份（可选）

在服务器上执行一次，之后每天凌晨 3 点自动备份数据库、只保留最近 7 天：

```bash
cat > /etc/cron.daily/hopzz-backup <<'EOF'
#!/bin/sh
mkdir -p /root/backup
sqlite3 /opt/hopzz-api/data/hopzz.db ".backup '/root/backup/hopzz-$(date +%F).db'"
find /root/backup -name 'hopzz-*.db' -mtime +7 -delete
EOF
chmod +x /etc/cron.daily/hopzz-backup
```

## 6. 系统更新

```bash
apt update && apt upgrade -y
```

建议**一到两个月跑一次**。更新内核后需要重启才生效：

```bash
reboot
```

> 重启不会丢东西：Nginx、后端、防火墙、fail2ban 全都是开机自启的。重启后等 30 秒再访问网站。

## 7. HTTPS 证书

证书是 Let's Encrypt 免费签的，**自动续期**，你不用管。想确认一下：

```bash
# 看证书到期时间
certbot certificates

# 看自动续期定时器
systemctl list-timers certbot.timer

# 手动测试续期（不会真的续，只是演练）
certbot renew --dry-run
```

> 重要：续期靠**80 端口**做验证，所以防火墙必须一直开着 80 端口（现在是开着的）。如果哪天你改了防火墙，记得别关 80。

---

## 8. 防火墙

```bash
# 看规则
ufw status numbered

# 开放一个端口（比如以后加个 8080 的服务）
ufw allow 8080/tcp

# 关闭一个端口
ufw delete allow 8080/tcp
```

> ⚠️ **千万不要** `ufw disable` 之后就重启，也别删掉 22 端口规则——那样你会连不上服务器。

## 10. 出问题了怎么办

按这个顺序排查，90% 的问题都能定位：

1. `systemctl status hopzz-api --no-pager` → 后端挂了？
2. `journalctl -u hopzz-api -n 50 --no-pager` → 后端为什么挂？
3. `systemctl status nginx --no-pager` → Nginx 挂了？
4. `tail -n 50 /var/log/nginx/error.log` → Nginx 报什么错？
5. `curl -s http://127.0.0.1:8000/api/health` → 本机后端通不通？
6. `curl -sI https://hopzz.top` → 从公网通不通？

**然后把这几条的输出发给我，我帮你看。**
