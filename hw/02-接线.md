# 02 接线：从“只插 USB”到“温湿度 + 继电器”

这一篇按**三步递进**来：

1. **最小系统**：只插 USB，点亮板载 LED，证明“板子、线、电脑”这三样没问题。
2. **接温湿度**：DHT22 三根线，串口能读到数字。
3. **加继电器**：用 GPIO 控制一个小灯或小风扇（**低压**）。

**每一步都要单独测试通过，再进下一步。** 不要一次把全部传感器插上；一起不工作的时候，你根本不知道是哪一根线的问题。

---

## 一、动手前的规矩

- **改线之前先拔 USB。** 插着电改线，手一抖 3.3V 碰到 GND，轻则重启，重则烧板。
- **认丝印，不要认位置。** 不同厂家的 30 针 ESP32 板子，引脚排列可能不一样。以板子背面/正面印的 `GPIO4`、`3V3`、`GND` 为准，不要背“第几根针”。
- **颜色只是给你自己看的。** 下面建议红线接 3.3V、黑线接 GND，但**通电前一定用丝印再核对一遍**，不要因为“颜色对”就放心。
- **ESP32 是 3.3V 逻辑。** 所有信号脚（GPIO）只能接受 0～3.3V，**不能接 5V**。传感器如果是 5V 供电、输出 5V 信号，必须加电平转换（level shifter）或分压，不能直连。
- **共地（common ground）**：所有模块的 GND 必须和 ESP32 的 GND 连在一起，否则信号没有参考点，读数会乱飞。

---

## 二、先认识你要用的引脚

下面这张表是**本教程的接线总表**。你不需要一次全部接，先看前三行（最小系统），再按步骤往下加。

| ESP32 引脚（丝印） | 接到哪里 | 线色建议 | 说明 |
|---|---|---|---|
| `3V3` | 传感器 VCC | 红 | 3.3V 输出，给 DHT22/SHT30/OLED 等小功率模块供电 |
| `GND` | 所有模块 GND | 黑 | 必须共地；至少留一个 GND 给传感器 |
| `GPIO2` | 板载 LED | 板载，不用接线 | 多数 ESP32 DevKit V1 的蓝色 LED 接在 GPIO2；用它做第一步测试 |
| `GPIO4` | DHT22 DATA | 黄 | 数字信号；DHT22 模块的数据脚 |
| `GPIO21` | SHT30/OLED/BH1750 的 SDA | 绿 | 默认 I2C 数据线（SDA） |
| `GPIO22` | SHT30/OLED/BH1750 的 SCL | 蓝 | 默认 I2C 时钟线（SCL） |
| `GPIO26` | 继电器 IN | 橙 | 数字输出，控制继电器吸合 |
| `GPIO34` | 电容式土壤湿度 AO | 紫 | **仅输入**，ADC1，WiFi 开启时也能用 |
| `GPIO35` | 光敏模块 AO / 模拟光照 | 灰 | **仅输入**，ADC1；如果买 BH1750 则不用这根 |
| `5V` / `VIN` | 5V 继电器线圈（如果买的是 5V 模块） | 红（粗） | USB 供电时这里有 5V；电流大时建议单独供电 |
| `GPIO25` | 外部 LED（可选） | 任意 | 数字输出；接 LED 要串 220Ω～1kΩ 电阻 |

> **重要：** `GPIO34`～`GPIO39` 是**只能输入**的引脚，不能输出高低电平，也没有内部上拉/下拉。拿它点 LED 是点不亮的，但读模拟量正合适。

### 逻辑接线图（不是物理位置图）

```text
                         ┌──────────────────────────┐
                         │      ESP32 DevKit V1     │
                         │      （30 针，3.3V）      │
                         │                          │
    DHT22 VCC  ──红线───►│ 3V3                      │
    DHT22 GND  ──黑线───►│ GND                      │
    DHT22 DATA ──黄线───►│ GPIO4                    │
                         │                          │
    SHT30 SDA  ──绿线───►│ GPIO21                   │
    SHT30 SCL  ──蓝线───►│ GPIO22                   │
    OLED  SDA  ──绿线───►│ GPIO21（和 SHT30 并联）   │
    OLED  SCL  ──蓝线───►│ GPIO22（和 SHT30 并联）   │
                         │                          │
    继电器 IN  ──橙线───►│ GPIO26                   │
                         │                          │
    土壤 AO    ──紫线───►│ GPIO34（仅输入 / ADC1）   │
    光照 AO    ──灰线───►│ GPIO35（仅输入 / ADC1）   │
                         │                          │
    USB 5V ─────────────►│ USB 口（供电）            │
                         └──────────────────────────┘
```

再次提醒：上图是**逻辑连接**。实际插线时，找到板子上印着 `3V3`、`GND`、`GPIO4` 的那几根针，不要按图上的左右位置硬套。

## 三、第一步：最小系统，只插 USB，点亮板载 LED

### 3.1 接线

**什么都不用接。** 只把 USB 线一头插电脑，一头插 ESP32 的 USB 口。

```text
┌────────┐     USB 数据线     ┌──────────────┐
│ 电脑   │ ─────────────────► │ ESP32 开发板  │
└────────┘                    │  板载 LED     │
                              │  接 GPIO2     │
                              └──────────────┘
```

### 3.2 你要观察什么

- 板子上应该有一个小 LED（通常是蓝色）开始**闪**。
- 如果插上后电脑“叮”一声，设备管理器里多了一个 COM 口，说明 USB 转串口芯片被识别了。
- 如果 LED 不闪、电脑也没反应，先别怀疑代码，去 [05-常见问题.md](05-常见问题.md) 看“插上没 COM 口”和“上传失败”。

### 3.3 上传哪个代码

打开 [code/01_blink.ino](code/01_blink.ino)，按 [03-环境与代码.md](03-环境与代码.md) 装好 Arduino IDE 后上传。

代码的核心就这几行：

```cpp
#define LED_PIN 2          // 多数 DevKit V1 的板载 LED 接 GPIO2
#define LED_ON  HIGH       // 如果你的板子是低电平点亮，把这里改成 LOW
#define LED_OFF LOW

void setup() {
  pinMode(LED_PIN, OUTPUT); // 把 GPIO2 设成输出
}

void loop() {
  digitalWrite(LED_PIN, LED_ON);  // 亮
  delay(1000);                    // 等 1 秒
  digitalWrite(LED_PIN, LED_OFF); // 灭
  delay(1000);
}
```

**为什么先点灯？** 因为点灯不依赖任何传感器、不依赖 WiFi、不依赖服务器。只要灯能按你的节奏闪，就证明：USB 线能传数据、驱动装对了、板子选对了、代码能编译上传。后面出问题，就可以排除这一大块。

> 有些板子的板载 LED 是**低电平点亮**（给 LOW 才亮），有些接的不是 GPIO2。如果你的灯不亮但程序上传成功，先把 `LED_ON` 和 `LED_OFF` 对调试试；还不行就查你板子的原理图/商品页，确认 LED 接哪个 GPIO。

## 四、第二步：接 DHT22 温湿度传感器

### 4.1 先断电

拔掉 USB。**所有接线都在断电状态下完成。**

### 4.2 认识 DHT22 模块的三个脚

常见的 DHT22 模块（带小 PCB）一般印着：

```text
┌─────────────────────┐
│  DHT22 模块          │
│                     │
│  VCC   DATA   GND   │  ← 三个排针
│   │      │      │    │
└───┼──────┼──────┼────┘
    │      │      │
   红      黄      黑
   3.3V   GPIO4   GND
```

不同模块的丝印可能是 `VCC / OUT / GND`、`+ / S / -`，意思一样：电源正、数据、地。**以丝印为准。**

如果你买的是**裸的 4 针 DHT22 元件**（没有小 PCB），引脚顺序通常是：

```text
DHT22 元件（正面看，引脚朝下）
┌───────────────┐
│  1    2    3    4  │
│ VCC  DATA  NC   GND│
└───────────────┘
   │    │    │    │
  3.3V GPIO4 不接  GND
        │
        └── 10kΩ 上拉电阻 ── 3.3V
```

- 第 3 脚 `NC` 是空脚，不接。
- **DATA 和 3.3V 之间必须加一个 4.7kΩ～10kΩ 的上拉电阻**（pull-up resistor）。模块版通常已经焊在板子上了，裸元件没有，必须自己加。
- 上拉电阻另一端接 **3.3V**，不要接 5V。

### 4.3 接线表

| DHT22 模块引脚 | 接到 ESP32 | 线色建议 | 说明 |
|---|---|---|---|
| `VCC` / `+` | `3V3` | 红 | 3.3V 供电，DHT22 工作电压约 3.3～5.5V，这里用 3.3V |
| `DATA` / `OUT` / `S` | `GPIO4` | 黄 | 单总线数据脚 |
| `GND` / `-` | `GND` | 黑 | 共地 |

```text
┌──────────────┐                    ┌────────────────────┐
│  DHT22 模块   │                    │  ESP32 DevKit V1   │
│              │                    │                    │
│  VCC  ●──────┼──── 红线 ─────────►│ 3V3                │
│  DATA ●──────┼──── 黄线 ─────────►│ GPIO4              │
│  GND  ●──────┼──── 黑线 ─────────►│ GND                │
│              │                    │                    │
│ （模块内部通常 │                    │                    │
│  已有 4.7k～  │                    │                    │
│  10k 上拉）   │                    │                    │
└──────────────┘                    └────────────────────┘
```

### 4.4 检查一遍再上电

- [ ] 红线在 `3V3`，不是 `5V`（DHT22 接 5V 也能工作，但数据脚会输出 5V，可能损坏 ESP32；统一用 3.3V 最稳）。
- [ ] 黑线在 `GND`。
- [ ] 黄线在 `GPIO4`。
- [ ] 没有线碰到旁边的针。
- [ ] 裸元件的话，上拉电阻确实接了。

确认后插 USB，上传 [code/02_read_sensor.ino](code/02_read_sensor.ino)，打开串口监视器，波特率 **115200**。你应该看到类似：

```text
温度: 26.5 °C  湿度: 58.2 %RH
```

如果显示 `NaN`（Not a Number，不是数字），说明没读到传感器。**先别改代码**，九成是接线、上拉电阻、或传感器型号选错（代码里 `DHTTYPE` 选了 DHT11 但实际是 DHT22）。去 [05-常见问题.md](05-常见问题.md) 看“传感器读 NaN”。

> DHT22 两次读数之间至少隔 **2 秒**。代码里 `delay(2000)` 就是干这个的。读太快会返回 NaN。

## 五、第三步：加继电器（只接低压负载！）

### 5.1 先确认你买的是哪种继电器模块

拿起模块，看丝印和商品页，确认：

- 供电 `VCC` 是 **3.3V** 还是 **5V**；
- 输入 `IN` 是 **高电平触发** 还是 **低电平触发**；
- 有没有 **光耦隔离**（通常板上有 4 脚小芯片，丝印 PC817 之类）；
- 是 **单路** 还是 **双路**。

本教程按**单路、3.3V 供电、低电平触发**来写。如果你的模块是高电平触发，代码里把 `RELAY_ACTIVE_LOW` 改成 `0`。

> **不要用 GPIO 直接驱动裸继电器线圈。** GPIO 只能输出很小的电流，线圈通常要几十到上百毫安，必须用带三极管/光耦驱动的**模块**。

### 5.2 接线表（控制端）

| 继电器模块引脚 | 接到 ESP32 | 线色建议 | 说明 |
|---|---|---|---|
| `VCC` | `3V3`（仅限 3.3V 模块） | 红 | 5V 模块接 `5V`/`VIN`，见下面的注意 |
| `GND` | `GND` | 黑 | 必须共地 |
| `IN` | `GPIO26` | 橙 | 控制信号 |

```text
┌──────────────────┐                  ┌────────────────────┐
│  继电器模块       │                  │  ESP32 DevKit V1   │
│                  │                  │                    │
│  VCC  ●──────────┼─── 红线 ────────►│ 3V3（3.3V 模块）    │
│  GND  ●──────────┼─── 黑线 ────────►│ GND                │
│  IN   ●──────────┼─── 橙线 ────────►│ GPIO26             │
│                  │                  │                    │
│  COM  ●──┐       │                  │                    │
│  NO   ●──┤ 负载   │                  │                    │
│  NC   ●──┘       │                  │                    │
└──────────────────┘                  └────────────────────┘
```

### 5.3 负载端怎么接（以 5V 小风扇为例）

继电器就是一个**用电磁铁控制的开关**：

- `COM` 是公共端（common）；
- `NO` 是常开端（normally open）：继电器不吸合时断开，吸合时接通；
- `NC` 是常闭端（normally closed）：继电器不吸合时接通，吸合时断开。

控制一个 5V 小风扇，用 `COM` 和 `NO` 就够了：

```text
       5V 电源正极
            │
            ▼
        ┌───────┐
        │  COM  │
        │ 继电器 │
        │  NO   │
        └───┬───┘
            │
            ▼
        ┌───────┐
        │ 风扇 + │
        │ 风扇 - │
        └───┬───┘
            │
            ▼
       5V 电源负极（和 ESP32 的 GND 共地）
```

- 继电器**不吸合**：COM 和 NO 断开，风扇不转。
- 继电器**吸合**：COM 和 NO 接通，风扇转。
- 风扇的电源可以用独立的 5V 电源；**独立电源的 GND 必须和 ESP32 的 GND 连在一起**（共地），否则控制信号没有参考点。
- 不要用 ESP32 的 `5V` 引脚直接给大电流风扇供电；电流大了会拉低电压，板子重启。

### 5.4 上传测试代码

打开 [code/02c_relay_test.ino](code/02c_relay_test.ino)，上传后继电器会每 3 秒“吸合 → 断开”循环。你应该能听到“嗒”的一声，模块上的指示灯也会亮/灭。

如果继电器不动作：

1. 先看模块上的电源灯亮不亮；不亮就是 VCC/GND 接错或没供电。
2. 看 IN 脚有没有信号；可以用万用表量 GPIO26 对 GND 的电压（低电平触发时，吸合瞬间应接近 0V）。
3. 确认你的模块是 3.3V 可触发；很多 5V 模块 3.3V 驱动不了。
4. 确认触发方式：低电平触发 vs 高电平触发，代码里改 `RELAY_ACTIVE_LOW`。
5. 继电器线圈电流大，USB 供电不足会导致板子重启，换 5V 1A 以上的电源。

> **再次强调：** 以上只适用于低压负载。220V 市电的接线、绝缘、外壳、保险丝，任何一项都不是新手能随手做的。**不要碰。**

## 六、进阶接线：SHT30、OLED、BH1750、土壤湿度

等你把 DHT22 和继电器都跑通，再考虑这些。**每次只加一个，加完单独测试。**

### 6.1 I2C 总线：SHT30、OLED、BH1750 可以并联

I2C（Inter-Integrated Circuit）是两根线的总线：`SDA`（数据）和 `SCL`（时钟）。多个 I2C 设备可以**并联**在同一对 SDA/SCL 上，靠不同的**地址**区分。

| 设备 | 常见 I2C 地址 | 接到 ESP32 |
|---|---|---|
| SHT30 | `0x44` 或 `0x45` | SDA→`GPIO21`，SCL→`GPIO22` |
| OLED SSD1306 | `0x3C` 或 `0x3D` | SDA→`GPIO21`，SCL→`GPIO22` |
| BH1750 | `0x23`（ADDR 接 GND）或 `0x5C` | SDA→`GPIO21`，SCL→`GPIO22` |

```text
                    ┌────────────────────┐
                    │  ESP32 DevKit V1   │
                    │                    │
    SHT30 SDA ●─────┤ GPIO21             │
    OLED  SDA ●─────┤  （同一根线并联）    │
    BH1750 SDA ●────┤                    │
                    │                    │
    SHT30 SCL ●─────┤ GPIO22             │
    OLED  SCL ●─────┤  （同一根线并联）    │
    BH1750 SCL ●────┤                    │
                    │                    │
    所有 VCC  ──────┤ 3V3                │
    所有 GND  ──────┤ GND                │
                    └────────────────────┘
```

注意：

- **VCC 全部接 3.3V**，不要接 5V。ESP32 的 I2C 引脚不耐 5V。
- 模块一般自带 4.7kΩ 上拉电阻。多个模块并联后上拉会变强（电阻并联变小），通常还能工作；如果 I2C 扫描不到设备，先拔掉其他模块，只留一个测试。
- 线尽量短，20cm 以内。I2C 线太长容易通信失败。
- 如果 SHT30 和 OLED 地址冲突（很少见），看模块上的地址跳线，或者换一个模块。

### 6.2 土壤湿度传感器

买**电容式**的，一般有三个脚：

| 传感器引脚 | 接到 ESP32 | 说明 |
|---|---|---|
| `VCC` | `3V3` | 用 3.3V，输出不会超过 3.3V |
| `GND` | `GND` | 共地 |
| `AOUT` / `AO` | `GPIO34` | 模拟输出，接 ADC1 引脚 |

- **只能用 ADC1 引脚**（`GPIO32`～`GPIO39`）。ESP32 的 ADC2（`GPIO0/2/4/12/13/14/15/25/26/27`）在 WiFi 开启时不能可靠工作。
- `GPIO34`、`GPIO35`、`GPIO36`、`GPIO39` 是**仅输入**引脚，正好用来读模拟量。
- 读数需要**标定**：完全干燥时记一个值，插进水里记一个值，中间按比例换算成“湿度百分比”。不同土壤、不同供电，数值会漂，别指望直接读出精确的含水率。
- 探头不要长期插在盐水/肥料水里，会腐蚀；用完擦干。

### 6.3 光敏模块 vs BH1750

- **光敏电阻模块**：便宜（约 3～5 元），输出模拟电压，接到 `GPIO35`。缺点是数值不是勒克斯（lux），只能大致判断“亮/暗”，而且不同模块差异大。
- **BH1750**：I2C 数字光照传感器，直接读 lux，约 6～12 元，推荐。接线见上面的 I2C 总线。

### 6.4 OLED 小屏

- 买 **4 针 I2C** 版：`VCC / GND / SDA / SCL`。
- 接 `3V3`、`GND`、`GPIO21`、`GPIO22`。
- 库用 **Adafruit SSD1306** + **Adafruit GFX Library**；如果是 1.3 寸 SH1106 屏，库不一样，买前确认。
- 地址通常是 `0x3C`。不亮先跑 I2C 扫描代码，确认地址。

## 七、哪些引脚不要用（重要）

ESP32 的引脚不是“每个都能随便用”。下面这些，新手先避开：

| 引脚 | 能不能用 | 原因 / 说明 |
|---|---|---|
| `GPIO6`～`GPIO11` | **不要用** | 接板载 SPI flash（闪存），占了这些脚，板子直接无法启动 |
| `GPIO0` | 尽量不用 | **启动脚**（strapping pin）。上电时被拉低会进入下载模式；板载 BOOT 键就是它 |
| `GPIO2` | 除板载 LED 外尽量不用 | 启动脚，且多数板子板载 LED 接这里；上电瞬间的外部电路可能影响启动 |
| `GPIO5` | 尽量不用 | 启动脚，上电电平会影响启动配置 |
| `GPIO12` | **不要用** | 启动脚（MTDI）。上电时必须为低；被外部拉高会让 flash 电压选错，板子起不来 |
| `GPIO15` | 尽量不用 | 启动脚（MTDO），上电电平会影响启动日志/启动模式 |
| `GPIO34`～`GPIO39` | **只能输入** | 没有输出驱动能力，也没有内部上拉/下拉；适合 ADC1 模拟输入 |
| `GPIO1` / `GPIO3` | 尽量不用 | 串口 `TX0` / `RX0`，下载和调试占用；接传感器可能影响上传 |
| `EN` | 不要接 | 复位脚，拉低会复位板子 |
| `3V3` / `5V` / `GND` | 电源，不是信号 | 接反会烧；5V 不能接到任何 GPIO |

**推荐的“安全引脚”**（数字输入/输出都行）：

```text
GPIO4, GPIO13, GPIO14, GPIO16, GPIO17, GPIO18, GPIO19,
GPIO21, GPIO22, GPIO23, GPIO25, GPIO26, GPIO27,
GPIO32, GPIO33
```

其中 `GPIO34`～`GPIO39` 只能当输入；`GPIO21/22` 默认给 I2C；`GPIO4` 本教程给 DHT22；`GPIO26` 给继电器。

> 关于启动脚，你不需要背电平表。记住一句话：**“GPIO0/2/5/12/15 上不要接会持续拉高或拉低的负载；GPIO12 尤其不能拉高。”** 拿不准就换到上面的安全引脚。

## 八、上拉电阻到底要不要加

| 场景 | 要不要加上拉 | 怎么加 |
|---|---|---|
| DHT22 裸元件 DATA | **要** | DATA 与 3.3V 之间接 4.7kΩ～10kΩ |
| DHT22 模块 DATA | 通常不用 | 模块一般已自带；如果读 NaN，可以再并一个 10kΩ 试试 |
| I2C（SHT30/OLED/BH1750） | 模块通常自带 | SDA、SCL 各自通过 4.7kΩ 接到 3.3V；多个模块并联时不要盲目再加 |
| 继电器 IN | 不要 | 模块内部有驱动电路，直接接 GPIO |
| 土壤/光敏模拟输出 | 不要 | 直接接 ADC 引脚；上拉会改变读数 |
| 按键 | 不用外部 | 用代码 `pinMode(pin, INPUT_PULLUP)` 开内部上拉，按键另一端接 GND |
| LED | 不是上拉 | LED 串一个 220Ω～1kΩ 限流电阻，再接到 GND |

**永远不要把上拉电阻接到 5V 再进 GPIO。** ESP32 的 GPIO 最大只能承受 3.3V。

## 九、接线完成后的自检清单

在通电之前，逐条打勾：

- [ ] USB 已拔掉。
- [ ] 所有 `GND` 都连到 ESP32 的 `GND`（共地）。
- [ ] 所有 `VCC` 都接 `3V3`，没有接 `5V`（除非你明确知道那个模块要 5V）。
- [ ] 没有 5V 线接到任何 GPIO。
- [ ] DHT22 的 DATA 接 `GPIO4`，不是 `GPIO5` 或 `GPIO2`。
- [ ] 继电器是 3.3V 可触发；如果是 5V 模块，IN 没有直连 GPIO（需要电平转换/驱动）。
- [ ] 没有线搭在 `GPIO6`～`GPIO11`、`GPIO12` 上。
- [ ] 裸 DHT22 的上拉电阻接了。
- [ ] 面包板电源轨没有短路（目测没有金属丝搭在一起）。

确认后，先插 USB，看板子有没有异常发热、有没有反复重启。正常的话，按顺序上传 `01_blink.ino` → `02_read_sensor.ino` → `02c_relay_test.ino`。

接线跑通后，去 [03-环境与代码.md](03-环境与代码.md) 学怎么装环境、怎么读懂每一行代码。
