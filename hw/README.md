# 从零做一台联网温湿度小站（ESP32 + hopzz.top）

这是一套写给完全新手的实操教程：**先买一套硬件，再接线，再写代码，最后把数据发到你自己的网站**。不需要你事先懂电路，也不需要你会写前端；只要照着步骤做，遇到问题去翻最后一篇排错。

服务器端（`hopzz.top` 的网站和 API）由另一位工程师负责。本教程负责的是**设备这一端**：买什么、怎么插线、代码怎么写、怎么把数据按约定发过去。

> 第一次看到不认识的英文缩写（GPIO、I2C、TLS、JSON……），直接翻到最后的“附录：术语小抄”。

---

## 一、学完这一套，你能得到什么

做出来之后，你手里会有一个巴掌大的小盒子（或者就摊在面包板上），它能做这些事：

- 每隔半分钟测一次房间的**温度**和**湿度**；
- 通过家里的 WiFi，把数据发到 `https://hopzz.top/api/telemetry`；
- 打开你的个人主页，就能看到最新一条温湿度；
- 留了一个**继电器**接口，以后可以控制小灯、USB 风扇这类**低压**电器；
- 预留了土壤湿度、光照、OLED 小屏幕的接法，想加就加。

整体数据流是这样：

```text
 ┌──────────┐   杜邦线    ┌──────────┐   2.4G WiFi   ┌────────┐
 │ DHT22    │ ──────────> │  ESP32   │ ────────────> │ 路由器 │
 │ 温湿度传感器│            │ 开发板   │               └────┬───┘
 └──────────┘             └────┬─────┘                    │ 互联网
                               │ USB 5V 供电               │
                          ┌────┴─────┐               ┌─────▼─────────┐
                          │ 充电头/电脑│               │ VPS 64.83.20.24│
                          └──────────┘               │ hopzz.top      │
                                                     │ /api/telemetry │
                                                     └─────┬─────────┘
                                                           │
                                                     ┌─────▼─────────┐
                                                     │ 你的个人主页    │
                                                     │ 显示最新温湿度  │
                                                     └───────────────┘
```

> 说明：图中的 IP `64.83.20.24` 是服务器地址，日常访问用域名 `hopzz.top` 就行。设备代码里也建议写域名，不要写 IP，因为 HTTPS 证书是按域名校验的。
>
> 当前服务端已经上线；在硬件接入之前，主页上的温湿度区域显示“还没有硬件上报数据”，这是正常的，接上设备后就会变成真实读数。

## 二、阅读顺序

**不要跳着看。** 这套教程是按“先能亮灯，再能读数，最后能联网”的顺序排的。

| 顺序 | 文件 | 你要完成的事 | 大概花多久 |
|---|---|---|---|
| 0 | 你正在看的 `README.md` | 了解全貌、预算、时间 | 5 分钟 |
| 1 | [01-选型.md](01-选型.md) | 下单买一套硬件 | 20 分钟 |
| 2 | [02-接线.md](02-接线.md) | 面包板接线，先点亮板载 LED | 40 分钟 |
| 3 | [03-环境与代码.md](03-环境与代码.md) | 装 Arduino IDE、编译上传、读串口 | 1～2 小时 |
| 4 | [04-连上服务器.md](04-连上服务器.md) | 连 WiFi，把温湿度 POST 到 hopzz.top | 40 分钟 |
| 5 | [05-常见问题.md](05-常见问题.md) | 出问题时按“现象 → 原因 → 怎么修”排查 | 随用随查 |

代码都在 [code/](code/) 目录里：

| 文件 | 作用 |
|---|---|
| [code/01_blink.ino](code/01_blink.ino) | 板载 LED 闪烁，验证“板子、驱动、上传”这条链路是通的 |
| [code/02_read_sensor.ino](code/02_read_sensor.ino) | 读 DHT22 温湿度，从串口打印出来 |
| [code/02b_read_sht30.ino](code/02b_read_sht30.ino) | 可选：读 SHT30（I2C 接口，进阶档传感器） |
| [code/02c_relay_test.ino](code/02c_relay_test.ino) | 可选：测试继电器（只接低压负载） |
| [code/03_post_to_server.ino](code/03_post_to_server.ino) | 连 WiFi，把温湿度 POST 到服务器，带重试和错误处理 |

> **注意：** Arduino IDE 把“一个文件夹”当成一个项目，同目录下多个 `.ino` 会被合并编译。`code/` 里放了多个实验，**不要直接打开整个 `code/` 文件夹**；每次只把要用的那个 `.ino` 复制到独立文件夹，或者新建 Sketch 后粘贴。具体见 [code/README.md](code/README.md)。

建议先把 `01`、`02` 跑通，再去碰 `03`。**一步一步来，比一次全接上然后一起排错快得多。**

## 三、预算合计

价格都是**约数**，来自常见电商平台的散件价；不同店铺、是否包邮、是否买套装，差别不小，**以你实际看到的店铺价格为准**。这里不推荐具体店铺，只推荐型号和规格。

| 档位 | 包含内容 | 预算 |
|---|---|---|
| 入门档 | ESP32 开发板 + DHT22 + 面包板 + 杜邦线（+ 可选继电器/OLED） | **约 100 元内** |
| 进阶档 | 入门档基础上，加 SHT30、BH1750 光照、电容式土壤湿度、双路继电器、OLED | **约 200～300 元** |
| 工具（可选） | 万用表、USB 电流表、收纳盒 | 约 30～80 元，不买也能开始 |

详细清单在 [01-选型.md](01-选型.md)。如果你现在只想花最少的钱验证“我能不能做成”，买**入门档**就够了，**不要**一上来把所有传感器都买了。

## 四、预计上手时间

- **纯新手，第一次碰单片机**：入门档从拆快递到串口看到温湿度，**约 2～4 小时**；其中一半时间可能花在装 USB 驱动和找 COM 口上，这很正常。
- **把数据发到服务器**：服务端 API 已经部署好的前提下，**约 40 分钟～1 小时**。
- **进阶档全部接完、调通**：再安排 **1～2 个晚上**。
- 建议第一次留出一个**完整的周末下午**，不要赶时间。遇到问题先看 [05-常见问题.md](05-常见问题.md)，别急着重买板子。

## 五、动手前的检查清单

在拆快递之前，先把这几件事确认好：

- [ ] 家里路由器有 **2.4GHz** 的 WiFi。ESP32 **不支持 5GHz**；很多路由器把 2.4G 和 5G 合成一个名字，需要进路由器后台分开，或者确认设备能连到 2.4G 频段。
- [ ] 知道 WiFi 的**名称（SSID）**和**密码**。名称建议先用纯英文/数字，避免中文 SSID 带来的编码问题。
- [ ] 电脑有可用的 USB 口（USB-A 或 USB-C，取决于你买的线）。
- [ ] 服务端已经部署好 `POST /api/telemetry`，并且你拿到了**设备令牌**（device token）。如果服务端还没好，先把 `01`～`03` 跑通，第 4 篇等通知再联调。
- [ ] 心态：**先让板子亮灯，再让传感器读数，最后才联网。** 任何一步不通过，都不要往下走。

## 六、三条保命提醒

1. **ESP32 的引脚是 3.3V 逻辑，不是 5V。** 不要把 5V 直接接到 GPIO 上，也不要把输出 5V 信号的传感器直接接 GPIO。接错可能当场烧板子。
2. **继电器板上有强电风险。** 本教程只让你用继电器控制**低压**负载（LED 灯带、USB 小风扇、玩具电机）。如果你要接 220V 市电，必须由有电工经验的人操作，并且断电、验电、绝缘、外壳一样都不能少。新手**不要**碰市电。
3. **接线前先拔 USB。** 插着电改线，手一抖就可能把 3.3V 和 GND 短路。改完线，检查一遍，再插电。

---

## 七、这套教程的边界

- 不教你从零写服务端。服务端由 Lead 按固定的 API 契约实现，设备端只需要按契约发请求。
- 不教你画 PCB、不教你焊接。面包板 + 杜邦线足够跑通。
- 不追求“工业级可靠性”。这是学习项目，先跑通，再谈稳定性和外壳。

## 附录：术语小抄（第一次看到缩写就来查）

| 缩写/术语 | 英文全称 | 一句话解释 |
|---|---|---|
| GPIO | General-Purpose Input/Output | 通用输入输出引脚，可以读电平，也可以输出高低电平 |
| 3.3V 逻辑 | 3.3V logic level | 引脚用 3.3V 表示“高”、0V 表示“低”；ESP32 不能直接接 5V 信号 |
| MCU | Microcontroller Unit | 单片机，ESP32 就是一颗带 WiFi 的 MCU |
| 面包板 | breadboard | 不用焊接、可以反复插拔的接线板 |
| 杜邦线 | jumper wire | 两头带插针/插孔、用来连接模块的线 |
| 上拉电阻 | pull-up resistor | 把信号线“默认拉到高电平”的电阻，DHT22 和 I2C 常用 |
| I2C | Inter-Integrated Circuit | 两根线（SDA/SCL）的总线，SHT30、OLED、BH1750 都用它 |
| SPI | Serial Peripheral Interface | 另一种总线，速度更快、线更多；本教程的 OLED 不买 SPI 版 |
| ADC | Analog-to-Digital Converter | 把模拟电压变成数字，读土壤湿度/光敏电阻要用 |
| UART | Universal Asynchronous Receiver/Transmitter | 串口，电脑上的 COM 口就是通过它和 ESP32 通信 |
| IDE | Integrated Development Environment | 集成开发环境，本教程用 Arduino IDE |
| Sketch | — | Arduino 对“一个项目/程序”的叫法 |
| Flash | — | 单片机里的闪存，存程序；GPIO6～11 接的就是它 |
| Brownout | — | 电压跌到阈值以下导致的复位，串口会打印 `Brownout detector was triggered` |
| NaN | Not a Number | “不是数字”，传感器读失败时常见 |
| HTTP | HyperText Transfer Protocol | 网页/接口传输协议，明文 |
| HTTPS | HTTP Secure | HTTP 外面套 TLS，加密并验证服务器身份 |
| TLS | Transport Layer Security | 负责加密和证书校验的协议 |
| CA | Certificate Authority | 证书颁发机构；`setCACert()` 用的是根证书（root CA） |
| API | Application Programming Interface | 服务端提供的接口，本教程是 `/api/telemetry` |
| JSON | JavaScript Object Notation | 一种文本数据格式，用 `{}` 和 `key:value` 表示数据 |
| Token | — | 令牌，服务端发给设备的“门禁卡”，放在 `X-Device-Token` 头里 |
| SSID | Service Set Identifier | WiFi 的名字 |
| IP | Internet Protocol address | 网络地址，例如 VPS 的 `64.83.20.24` |
| DNS | Domain Name System | 把域名 `hopzz.top` 解析成 IP 的系统 |
| NTP | Network Time Protocol | 网络对时协议，ESP32 校验证书前要先对时 |
| CORS | Cross-Origin Resource Sharing | 浏览器的跨域资源共享规则，网页和 API 不同源时会遇到 |
| 波特率 | baud rate | 串口速度，本教程用 115200；两边不一致就乱码 |
